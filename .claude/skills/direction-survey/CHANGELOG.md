# 🚀 v3.0.3（2026-09-19）— 适配「已分析」按发表年分层

> 来源：paper-analyzer 于同日发布 **v4.1.0**，归档出口由 `已分析/<论文名>/` 改为 **`已分析/<发表年>/<论文名>/`**（见该 skill `CHANGELOG.md` v4.1.0 块）。

## 1. 为何必须适配

本 skill 的扫描入口是 `已分析/` 的直接子目录（`ds_scan.py` 的 `scan_papers()` 原先直接
`iterdir()` 取论文文件夹）。年份层一加，`已分析/2020/` 这类**年份目录会被误当成一篇"论文"**，
其下真正的论文文件夹全被漏掉——篇目、报告路径、引擎版本、锚点全错。属**功能性适配**，非纯戳对齐。

## 2. 改动（仅 `scripts/ds_scan.py`）

| 位置 | 改动 |
|------|------|
| 新增 `YEAR_DIR_RE` + `iter_paper_dirs()` | 遍历 `已分析/` 直接子目录：名称匹配四位数字或 `年份不详` → 视作年份层，**下探一层**再取论文文件夹并回传层名；否则按旧扁平布局直接产出（层名 = `""`）。**两种布局并存都认** |
| `scan_papers()` | 遍历改用 `for paper_dir, year in iter_paper_dirs(analyzed_root):`，record 增 `rec["year"] = year` |
| `scan_discipline()` | 方向内 `analysed[]` 每条增 `"year"` 字段（取自 record） |
| 控制台打印 | 方向级逐篇前缀 `[<年份> ｜ <引擎> / <结构>]`（旧扁平无年份则不打前缀） |
| 模块 docstring | 补年份层说明与两种布局口径 |

## 3. 零改动项（明确声明）

- **存量产物不追溯回改**：已发件的方向综述 / 学科论断（2026-09-18 版）不重渲染、不重生成——其证据为报告正文，与目录层级无关。

## 4. 模板关联戳跟进

`templates/方向综述-模板.md`、`templates/学科方向论断-模板.md` 两处的「关联」行随本次一并升：

## 5. 验证（新布局实测）

# 🚀 v3.0.1（2026-09-18）— 渲染缺陷修复：边标签被白底框遮挡

> 来源：2026-09-18 重跑 SE 方向综述时发现（G2 图上 `[k]` 编号"缺失"），逐像素核验后确认为渲染器缺陷。
> 修复前快照：`存档/skills-前版本/direction-survey-v3.0-2026-09-18-渲染修复前/`（整份：`SKILL.md` + 本文件 + `scripts/` + `references/` + `templates/`）。

## 1. 缺陷 ⭐⭐⭐⭐⭐
- `scripts/ds_fig.py` 的 `_edge_arrow()` 为标签先画**白底衬框**（`fig.rbox(..., z=4)` → `FancyBboxPatch(zorder=4)`），随后用 `fig.text(...)` 画文字**未给 zorder** → `ax.text` 默认 **zorder=3**；同一坐标系内按 zorder 绘制 → **框画在字上面，字被自己的衬框整块盖掉**。
- 影响面：**G1**（`stage_edges` 的阶段间转向箭头文字）与 **G2**（泳道内边标签 + 跨族虚线编号 `[k]`）；G3 `quad` / G4 `audit` / T1 `terrain` 不走 `_edge_arrow`，**不受影响**。
- **`--qa` 测不出**：几何自检只做「文字外接框是否出画布 / 两两压叠」的量的比较，**不检查遮挡关系**（框与字同心同尺寸，量出来"零压叠"）。故 **`--qa` 退出码 0 不蕴含"看得见"**——本轮实跑就是「QA 全过但图上少 5 处编号」。

## 2. 修复（两行）
- `_edge_arrow` 内两处 `fig.text`（编号 `[k]` 与标签）补 **`zorder=5`**：框在下（z=4）、字在上（z=5），与文件内既有写法一致（如 quad 的点标 patch z=6 / 字 z=7）。
- 全文件复核：其余 `fig.rbox` 调用的 `z` 均为 `≤3` 且文字沿用默认 `z=3` 且**后画**（同 z 时后画者在上），**无同类缺陷**；`pa_fig.py` 的标签用 `ax.text(..., bbox=...)`（衬底随文字本体绘制，不经独立 patch），亦无此问题。

## 3. 逐像素核验（修复判定证据）
| 图 | 差异像素 | 差异区域 | 关键证据 |
|---|---|---|---|
| G1 发展时间线 | 2294 | 行 123–142（一条带，x 899–2908） | 该带暗像素 7280 → **8677**（阶段间箭头文字出现） |

# 🚀 v3.0（2026-09-18）— 学科级模式：学科细分方向论断 + T1 学科地形图

> 依据：用户提出「通过 skill-creator 为 direction-survey 增加学科细分方向的论断能力」。此前该 skill 只有**方向级**能力（一次只能综述一个 `<方向>`），对「这个学科该分成哪几块、哪块成熟哪块空、哪块该重切」完全没有能力位。
> 升级前快照：`存档/skills-前版本/direction-survey-v2.1-2026-09-18/`（整份，含 `快照说明.txt`；`__pycache__` 未纳入）。

## 1. 新增学科级模式（第二模式）⭐⭐⭐⭐⭐
- **输入** `论文库/<学科>`（而非 `<方向>`）→ **输出** `<学科>/方向论断/学科方向论断-<YYYY-MM-DD>.md(.docx)` + `assets/T1学科地形图.png` + 可复跑 `工作/{学科档案.json, fig_T1学科地形图.json}`。
- **方向级模式（输入/输出/G1–G4/七步流程）完全不变**，两种模式并列不混用（一个 `<方向>` 出 G1–G4，一个 `<学科>` 出 T1）。
- 触发词（写进 `description`）：这个学科分成哪几个方向 / 细分方向论断 / 学科地形 / 哪块成熟哪块空白 / 学科的刀该怎么切。

## 2. 论断口径：四要素 + 边界 + 样本不足纪律 ⭐⭐⭐⭐⭐
- 每块细分方向给**成立度**（成立/部分成立（边界模糊）/存疑）、**成熟度·活跃度·空白度**（低/中/高，各带一行判据）、**边界一句话**、**库内样本数**；空白度沿用 opportunity-method 的四条判据，明确「空白度高 ≠ 该投」。
- **切分判据四条**（独立任务定义 / 骨干或评测独立 / 连续谱系 / 库内可落地）——并立红线：**「实时/轻量/低资源/某数据集/某指标」是约束不是方向，不许占一行**。
- **样本不足纪律（硬约束）**：方向库内 <2 篇 → 该行标「样本不足·推断」；**篇数够但独立研究线 <2 条（同源衍生对：学位论文章节 = 期刊预印本、同一作者组互引）→ 按 1 条线计，同样标**；学科铺开 <3 块 → 学科级结论只能写「本库目前只铺开这几块」，不得声称全景；库内 0 篇 → 不填三要素。判法权威文件：新增 `references/discipline-method.md`。

## 3. 新开一刀的证据门 ⭐⭐⭐⭐
- 允许在地形图上新增「论断新增候选」行（本库尚未建目录的细分方向），但**必须过门**：切分判据 1–3 + （≥2 篇报告的 §5 锚点聚集 **或** 贴切的未分析 PDF）。
- **库外新检索（S2/OpenAlex/arXiv…）与未分析 PDF 一律只作「待读候选」，不参与成立度/成熟度/活跃度/空白度打分**——新检索分不清「真没人做」与「我们没检索到」，用它判空白度＝拍脑袋。
- 未过门的刀只进报告 §4「候选方向（证据不足）」，**不进图**。

## 4. 脚本与图型 ⭐⭐⭐⭐
- `scripts/ds_scan.py`：新增 `--discipline` 模式 → 逐方向清点（篇目/报告引擎与结构变体/**§5 `anchor_marks` 命中**/是否有方向综述件/未读 PDF）+ 样本充足性提示 → `学科档案.json`；**缺省方向级行为不变**。顺带修 `ENGINE_RE` 不认 markdown 粗体 `v**4.0**` 的漏检（此前一律报「未标注」）。扫学科时自动跳过自己的产物根 `方向论断/`。
- `scripts/ds_fig.py`：新增 `render_terrain`（`fig:"terrain"`）——行=细分方向（分带 `库内已建目录`/`论断新增候选`），列=成立度(胶囊)/成熟度/活跃度/空白度(**分级格**：色深=取值高，各维一色 blue/red/green，`不详` 为合法档)/库内样本/边界一句话；底部「学科级结论」条 + 两排图例（分级色阶 / 成立度三色）。
