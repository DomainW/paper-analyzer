# 学科细分方向论断法（discipline-method）

> **学科级模式（v3.0）专用**。方向级「这个方向怎么走过来的」用 `opportunity-method.md`；本文件回答另一类问题：**「这个学科现在其实是几块？哪块成熟、哪块还空、哪块本不该这么切、有没有该切而没切的一刀？」** 学科级的产物是**论断**（有成立度的判断），不是描述。

## 一、学科级与方向级的分工

| | 方向级（v2.1 模式，不变） | 学科级（v3.0 新增） |
|---|---|---|
| 输入 | `论文库/<学科>/<方向>` | `论文库/<学科>` |
| 产物 | `<方向>/方向综述/方向综述-<日期>.md` | `<学科>/方向论断/学科方向论断-<日期>.md` |
| 图 | G1 stage / G2 family / G3 quad / G4 audit | **T1 学科地形图**（`fig:"terrain"`） |
| 回答 | 这个方向怎么走过来的、岔成几股 | 这个学科该分成哪几块、各块什么状态、该不该重切 |
| 单位 | 阶段 / 技术家族 | **细分方向（格子）** |

**学科级不替代方向级**：地形图每格只给一行判据，深挖仍在各方向的 `方向综述`。两处口径必须一致（同一方向在地形图与方向综述里的边界/成熟度判读应对得上）；不一致 → 以报告证据为准，并把冲突记进缺口。

## 二、切分判据：什么才算一个「细分方向」

一个候选要在地形图上占一行，四条**同时**成立：

1. **有独立任务定义**：一句话说清「输入什么 / 输出什么 / 成功判据是什么」，且与邻块不同——不是同一任务换骨干。
2. **骨干 / 表示域 / 评测协议 至少其一独立**：否则它只是别方向的子技术（子技术进方向图，不占学科行）。
3. **有可追溯的连续谱系**：至少 2 篇可点名前驱或后继（库内已分析，或各报告 §5 锚点）。
4. **库内可落地**：本库至少有 1 篇已分析报告或 1 个方向目录。

> **红线（最常见的错切）**：「实时」「轻量化」「低资源」「因果」「某数据集」「某指标」是**约束/切法**，不是细分方向。它们应当成为块内的属性，或地形的**列**（如空白度判据之一），**不许单占一行**。
> 同理：「时域 / 时频域 / 复数域」是**表示域**——只有在它自带独立任务定义时才成块，否则是同一块内的家族划分（归方向级的 G2）。

## 三、四要素口径（逐格怎么判）

| 要素 | 取值 | 判据（命中越多越强） | 证据来源 |
|---|---|---|---|
| **成立度** | 成立 / 部分成立（边界模糊）/ 存疑 | 成立＝四条切分判据全中且叫法稳定（≥2 篇独立报告用同一任务词）；部分成立＝任务定义清楚但与邻块交叠（同一批论文被两种切法都收）；存疑＝只有单一报告/单一锚点支撑，或名字像约束不像任务 | 库内报告 §1/§2 任务定义段；锚点标题用词 |
| **成熟度** | 低 / 中 / 高 | 高＝骨干**跨族**收敛 + 协议稳（有公开基准，或库内可两两对比的数值）；中＝任务定义与阶段骨架已稳、**族内**各有同表基线，但骨干或协议只在族内收敛（跨族不可比）；低＝任务定义或骨干仍在移动（还在换骨、或评测词汇本身未定）。**族内收敛 ≠ 成熟度高**：三族各用各的骨干且互不继承，就是「中」不是「高」 | 报告 §2.3/§3.3；G4 式协议互斥情况 |
| **活跃度** | 低 / 中 / 高 | 高＝近 1–2 年锚点密集指向同一批工作 **且** 库内近两年仍有新报告入账；中＝有产出但换代慢；低＝近两年无新锚点聚集 | 报告 §5 R2/R4 锚点年份与聚集度 |
| **空白度** | 低 / 中 / 高 | 沿用 `opportunity-method.md` §三 四条判据：无共享可跑基准 / 关键主张无同表复核 / 现役×现役交叉未试 / 缺开源实现与真机实测——命中越多越高 | 报告 §4 缺口 + 资源清单 ⛔ 项 |

- 每格必须有 `why` **一行**（图上就写这一行）；完整论证进报告正文。
- 证据不足且无法降级的格 → 填 `不详`（图上有专用画法），**不许猜档位**。
- **空白度高 ≠ 该投**：又冷又空要先判「没人注意」还是「已验证走不通」——这与 G3 quad 的读法一致。

## 四、边界一句话

格式固定：`与 <邻方向> 的边界：<判别性差异>`，如「单目标 vs 多说话人」「是否引入说话人条件」「信号域切分 vs 任务切分」。

- 边界写不出 → 说明这块还没切干净：**成立度不得填「成立」**（降为缺「部分成立」或「存疑」）。
- 边界与邻块重合度 >50% → 两块应合并，或改切法；在地形图注里说明为何暂不合并。

## 五、样本不足纪律（硬约束）

| 情形 | 强制动作 |
|---|---|
| 方向库内 **n < 2 篇** | 样本列**必须**写「样本不足·推断」；三要素最多按已知证据给档，其余填 `不详`；报告正文该块所有结论加「（样本不足·推断）」 |
| 库内 **独立研究线 < 2 条**（篇数够但同源） | 篇数不算数，按独立线计。**同源衍生对**（学位论文章节 = 同组会议/期刊版、同一作者组的两篇互引）只算 **1 条线** → 同样标「样本不足·推断」。判别看**作者组 + 题目 + 方法同源**（脚本不代判，由撰写者判读），并在样本列写明「同源衍生对，实为 1 条线」 |
| 全学科铺开方向 **< 3 块** | 学科级结论只能写成「本库目前只铺开这几块」，**不得**声称学科地形/全景；结论条加「（样本不足·推断）」 |
| 库内 **0 篇**（仅锚点） | 该行不填成熟度/活跃度/空白度，只填边界一句话 + 待读候选，标注「未建目录（待读候选）」 |

`ds_scan.py --discipline` 会把上述提示写进 `学科档案.json` 的 `notes`；**照单执行，别因为「判断得很有把握」就省掉标注**——纪律约束的是证据量，不是自信度。

## 六、新开一刀的证据门

「新开一刀」＝ 在地形图上新增一个库内还没建目录的细分方向行（带 `论断新增候选`）。必须**过门**：

1. **锚点聚集**：≥2 篇已分析报告的 §5 锚点指向同一批库外工作（且是 ≥2 篇不同锚点）；或
2. **未分析 PDF 贴切**：`未分析/`（含 `论文库/_未分类/未分析/`）里有明显属于该刀的 PDF——只能作「待读」证据，不算已读；
3. **过切分判据 1–3**（任务独立 / 骨干或评测独立 / 有连续谱系）；
4. 且不是把约束（实时/轻量/低资源）当刀。

未过门 → 只能写进正文 §机会「候选方向（证据不足）」，**不进地形图**。

每把新刀在报告里写清四件事：**刀口在哪**（切什么、怎么切）／**与邻块边界**／**现有证据**（几条锚点、哪个 PDF、出处）／**还缺什么**才能建目录（一句话可执行动作）。

## 七、证据来源与红线

- 只认两类证据：① 库内已分析报告的 §1/§2/§4/§5；② 各报告 §5 收录的库外锚点（保留「锚点≠已读」属性）。
- **库外新检索（Semantic Scholar / OpenAlex / arXiv…）不得作为论断证据**：新检索到的一律进「待读候选」，标检索来源与检索词，**不参与**成立度/成熟度/活跃度/空白度打分。理由：新检索分不清「真没人做」与「我们没检索到」，用它判空白度＝拍脑袋。
- 未分析 PDF 同理：只作待读候选。
- 锚点缺元数据 → `年份?`；不臆造年份/指标/论文存在性；两报告口径冲突 → 记缺口，不取中值。

## 八、论断与 T1 地形图 / 报告的对应

- 地形图 **T1 一行 = 报告 §3 一小节**；**带内按成熟度降序**排（先成熟后新芽），另设「论断新增候选」带放新刀。
- 图上 `why` ≤1 行、边界 ≤1 句；论证、反例与缺口留正文。
- 图上不出现「推测」以外的模糊词；凡正文写「推测/待核」的，图上对应格必须标 `不详` 或写明「样本不足·推断」——**图与正文不许一个更硬一个更软**。
