# 报告逐章写法（report-structure）

> 指导步骤 6 用模板 `templates/方向综述-模板.md` 组装。目标：**方向演进中深综述**，md 正文 ~8000–1.4 万字（叙事主线 + 表格 + 图读法），docx 同源转换。
> 关键转向（v1→v2）：**叙事单元是"阶段"和"技术家族"，不是论文**。逐篇横评大表与档案**已移除**——只剩附录 A 一行/篇的定位索引。
> v2.1：图扩为 **G1 阶段演进 / G2 家族泳道 / G3 机会象限(quad) / G4 生态盘点矩阵(audit)** 四张，每张紧跟「图读法」；本节按现状骨架写。
> **v3.0**：本文件只管**方向级（G1–G4）**报告。**学科级**报告（T1 学科地形图 + 细分方向论断）另用 `templates/学科方向论断-模板.md`，逐章写法见 `discipline-method.md`（切分/四要素/样本不足/新开一刀证据门），骨架不同、不要混用。

## 各章要点

### 速览卡
结论不是过程：方向一句话定位 → 已走过哪些阶段/正处在哪 → **现分几大技术家族** → 主干史一句 → 前沿 1 句 → 最大瓶颈 1 句 → 最肥机会 1 句（含待读候选先读哪篇）。

### §1 口径与图例
- 开头一句**目标声明**（v2 独有）：本综述讲方向怎么发展，不是逐篇测评；单篇详情在附录 A。
- **统一图例**（覆盖四张图）：①颜色=身份（金实=库内 / 浅虚=库外锚点）；②线型（实=谱系继承 / 虚=跨族·只画相邻泳道 / G3 四区底色=机会象限，**右上又热又空最该投**）；③画布概念 = 带=阶段(G1)、道=家族(G2)、象限区=G3、粗黑带=研发谱系(G4)。
- 口径：纳入范围、v2/v3 归一、同源去重决策、未读锚点不代表已核指标。**篇幅减半**（v1 塞太多声明，v2 尽量在"图例"解决；G3/G4 的语义细节写进各自图读法）。

### §2 发展总览（G1）
- 先写一句话史：起源（哪年哪个工作定任务）→ 谁把主流骨干引入 → 何时主流成型 → 现在岔成几股。
- 阶段驱动表 3–5 行：`| 阶段 | 时期 | 代表工作 | 标志突破(方向级) | 遗留(方向级) |`。
- 嵌 G1 图 → 紧跟**图读法**（结构见 figure-design）。
- 逐阶段 1–2 段**驱动故事**：这段为什么发生、关键转折、代表工作一句话、遗留如何通向下阶段。**不逐篇展开数字**。

### §3 技术家族与分岔（G2 · G4）
- 3.1 家族地图文字快照：K 家族各一句（关键词/擅长约束/代表/卡点）+ 跨族一句话。这是全报告的结构锚点。
- 3.2 嵌 G2 泳道图 → **图读法** → **边注表**（编号→关系→依据；跨族虚线只画相邻泳道，隔泳道关系记〔文字·未画线〕）。
- 3.3 各家族小节：**写家族不写论文**。谱系链文字（`a → 库内x → 下游y`）、沿革 2–4 句、卡点带出处。指标只在证明家族论点时给 1–2 个并带口径。
- 跨家族互补/竞争小段：谁抢同一评测/约束、谁借谁模块、评测可不可通约（不可通约 → §6 缺口）。
- **3.4 生态盘点矩阵（G4, fig:"audit"）**：行=方法（粗黑带=研发谱系，金实=库内），列分三组（方法 / 评测协议：带宽·主指标·评测构型 / 复杂度口径：参数·算力·因果延迟）。嵌图 → **图读法**：先看几条谱系带、找带内同协议可排序子集、跨带/跨口径只并列不比较。诚实纪律：协议互斥（48k/16k/8k）与单位互斥（%CPU/RTF/MACs）如实并排，note 写「只有带内同协议可比」+ 给唯一可排例子；无数值、只给目标的下游锚点不入表、作文字。

### §4 前沿/瓶颈/机会（G3 quad）
- 判读法见 opportunity-method；写法以家族/方向为单位，给 2–4 前沿子题、三桶瓶颈、3–6 机会。
- 嵌 **G3 quad** → 图读法 3 句：x=机会空间/空白度（**越右=越没人系统做**）、y=前沿活跃度（越高越热）、**右上=又热又空=最该投**；sub 载判据消除歧义；正文说哪个点在右上，它就得真放 x,y>0.5。
- 每条判断带证据尾注；无证据进 §6 显式标推测。

### 附录 A 论文定位索引（v2 把逐篇挪到这里）
| 论文(年, 库内/锚点) | 家族·阶段 | 贡献一句话(方向口径) | 现状/短板一句(出处) | 关键指标(口径,1–2 个) |
- 一行/篇，**不给方法/损失分解**。指标必须带口径、与报告核对；锚点行不造假数值（无则 `—`）。

### §6 缺口/待核（信用账本）
方向级三类：①跨家族/跨阶段该连没连的边 ②数值口径不可通约（48k/16k/8k 之类，非冲突）③库外锚点缺失元数据。**宁多列不粉饰**。

## 例段（§3 家族小节，方向级写法）
> **家族 B · 时域状态空间（16k 轻量实时）**。谱系：`time-domain SpeakerBeam(2020) → SpeakerBeam-SS(2024, 库内) → Dual-Mode(2025, 训练策略)`。这族把"实时"当第一约束：Conv-TasNet-based TSE 骨架沿用十年，S4D 状态空间在 2024 首次入网，用大窗过参数化把 CPU RTF 压到 0.36（单核 EPYC 实测，SB-SS 报告 Table 1）。卡点：其 RTF 削减主因是大窗长而非 S4D，且只在服务器 CPU 实测（SB-SS §4.5 Top-1）——"通用 CPU 实时"外推证据不足。
> （对照 v1 会把 SB-SS 拆成一篇档案 + 横评行；v2 只保留"支撑家族论点"的两个数字。）
