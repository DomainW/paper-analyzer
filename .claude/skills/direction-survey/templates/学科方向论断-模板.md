## 1. 口径与图例（本篇怎么判、什么不算证据）

**目标声明**：本报告回答「这个学科**现在其实是几块、哪块成熟、哪块还空、哪块本不该这么切、有没有该切而没切的一刀**」。它是**论断**（每条判断带成立度与证据），**不是**方向演进综述的替代：某块「怎么走过来的」请看该方向的 `方向综述-<日期>.md`。

**四要素口径**（逐格判法见 `references/discipline-method.md` §三）：
| 要素 | 取值 | 一句话判据 |
|---|---|---|
| 成立度 | 成立 / 部分成立（边界模糊）/ 存疑 | 任务定义独立 + 骨干/评测独立 + 有连续谱系 + 库内可落地，四条全中才是「成立」 |
| 成熟度 | 低 / 中 / 高 | 骨干收敛度 × 评测协议稳定度 |
| 活跃度 | 低 / 中 / 高 | 近 1–2 年锚点聚集度 × 库内近年新增报告 |
| 空白度 | 低 / 中 / 高 | 无共享基准 / 无同表复核 / 现役×现役未试 / 缺开源与真机实测，四条命中越多越高 |
> 空白度高 **不等于** 该投：又冷又空要先判「没人注意」还是「已验证走不通」。

**样本不足纪律（硬约束，见 discipline-method §五）**：
- 某方向库内 **<2 篇** → 该行样本列写明「样本不足·推断」，正文该块结论全部加此标注；
- 全学科方向 **<3 块** → 学科级结论只能写「本库目前只铺开这几块」，**不许**声称学科全景；
- 库内 **0 篇** → 只给边界与待读候选，不填三要素。

**证据门（红线）**：
- 只认 ① 库内已分析报告 §1/§2/§4/§5；② 各报告 §5 收录的库外锚点（**锚点 ≠ 已读**）。
- **库外新检索（S2/OpenAlex/arXiv 等）不作论断证据** → 一律进 §4「待读候选」并标检索来源与检索词，不参与打分。
- 未分析 PDF 同样只作待读候选。
- 锚点缺元数据 → `年份?`；不臆造年份/指标；两报告口径冲突 → 记缺口，不取中值。

**T1 图例**：行 = 一个细分方向（分带：`库内已建目录` / `论断新增候选`）；列 = 成立度 / 成熟度 / 活跃度 / 空白度 / 库内样本 / 边界一句话。**色深 = 该维取值高**（低/中/高三档，各维一色）；`不详` = 证据不足，不许猜档。
