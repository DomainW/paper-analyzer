**统一图例**（四张图分工：G1 阶段演进 / G2 家族泳道 / G3 机会象限 / G4 生态盘点矩阵）：
- 节点/行颜色 = 身份：实心金 = 库内已分析（`this`）；浅色+虚线框 = 库外未读锚点，角色配色 `pre=绿 / rival=红 / module=蓝 / next=紫 / adj=灰蓝`。
- 实线边 = 同一谱系内的继承/承接；虚线边 = 跨家族借用（G2 里带编号 → 看**图下边注表**；**只画相邻泳道**，隔泳道关系为文字边）。
