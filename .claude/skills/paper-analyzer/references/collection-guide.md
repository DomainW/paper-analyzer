# 复现资料收集方法词典（collection-guide）

> **⚠️ 按需文档（v4.1.0 起）**：只在**要建/要维护 `资源清单.md`** 时才查本文件（SKILL.md 步骤 6 · 按需；paper-reproducer 复现时亦用）。默认分析不涉及。
> 配合 `templates/资源清单-template.md` 六类清单使用：本文件回答 **"每一类每一项具体怎么收、收完放哪、收不动时怎么办"**。
> 状态四态：`☐` 未收集 ｜ `🔄` 收集中 ｜ `✅` 已收(可复现用) ｜ `⛔` 受阻(需用户介入 / 等开源 / 未公开)。
> 维护：paper-analyzer（分析收尾建清单初稿）+ paper-reproducer（复现照单收集回写）。

## 1. 通用原则与红线

- **许可三条线分开记**：代码许可 / 数据许可 / 权重许可不一定相同，逐条登记。
- **不代下载受限数据**：VB、LDC、需登录/申请的数据——只记官方入口 + 许可，由用户手动放入后登记。
- **不自改结果凑指标**：收集是为复现，任何指标不符走差异分析，与本 skill 复现纪律一致。
- **任何一项找不到**：写"无/未找到"+ 状态 `⛔` 及一句下一步检索词，不留空、不虚报 ✅。
- **能浅克隆不深克隆**：小仓库 `gh repo clone` 浅克隆进镜像；超大仓库只记链接 + 说明。
- **时间盒**：单篇检索 15–20 分钟；未确认项进清单「待查」而非无限查下去。
- Windows 注意：仓库/文件夹命名禁半角 `:`；下载/克隆含中文路径时加引号。

## 2. 类 1 · 论文与文档

**收集清单**：论文 PDF、提取文本（`.txt / -layout.txt / -health.json`）、分析报告、补充材料 / 勘误 PDF、项目主页快照。

**方法**：
1. PDF/文本/报告 = 分析流程已收，核对 `原文/ 分析/` 即可，多数直接标 ✅。
2. 补充材料（supplementary/表 S1…）：论文页面（期刊主页 / arXiv / OpenReview）找 "Supplementary Material" 链接 → 下载到 `资料/补充/`。
3. 勘误 / 作者主页版本更新：Semantic Scholar 或 arXiv 版本页看有无 v2/erratum → 记录差异为**版本注**。
4. 项目主页快照：GitHub README 拿来做环境/版本入口；`curl` 抓主页存 `.html` 或直接记 URL（"仅链接"即算收齐）。

## 3. 类 2 · 官方代码与实现

**优先查作者发布**（顺序）：论文 footer/致谢/作者主页 → 按模型名搜 GitHub（`pa_query.py github "[模型名]" "speech enhancement"`）→ PapersWithCode → 引文里的官方链接。

**官方仓库收集方法**：
```bash
# 小仓库 → 浅克隆进镜像（保留 .git 以便核对 commit）
gh repo clone <owner>/<repo> "资料/official-代码/<repo>" -- --depth 1
# 或整包下载 zip（无 gh/网络受限时）
# 超大仓库 / 只做镜像参考 → 只记 URL + 版本 commit，标注"仅链接"
```
- **记录 commit**：复现前核对 commit 与论文（预印本 vs 正式版）是否同一版本 → 不一致记**版本注**。
- 大文件（权重）不入仓库镜像，放类 4；requirements/config 随代码镜像即算收齐。

**未开源 → 状态 `⛔（未公开）`**，不干等：
- 复现改走 **手搓路径**（implementation-guide/provenance-guide：拆组件 → 按论文规格实现 → 结构自检先行）；
- 清单备注写"无官方 → 手搓蓝图见 `分析/` 报告 §4"，并在 §7 待办登记"邮件作者可先问一次"。

**第三方 / 社区复现**：只列与本论文方法**直接相关**（基线/模块来源）；判相似用「作者团队 / 同名架构 / 复现了同表」；否则不列。

## 4. 类 3 · 数据集与 manifest

**公开可再分发**（许可允许）→ 下载到 `数据/<数据集>/`，下载脚本留 `数据/下载脚本/`：
| 数据来源 | 怎么下 |
|---------|--------|
| OpenSLR / 官方镜像 | `wget -c` 脚本化，断点续传 |
| Zenodo / Figshare | 页面直链或 API（`records/.../files`）|
| Hugging Face datasets | `huggingface-cli download <repo>` 或 `datasets` 库 |
| GitHub 上打包数据 | 浅 clone / zip |
> 下载后校验条数/采样率与 manifest 一致（这是对齐第一步坑）。

**受限（需申请/登录）** → 不代下：记官方入口 + 许可，请用户手动放入，状态 `☐/🔄（需用户放入）`；用户放入后登记路径与许可 → 改 ✅。

**作者自建 / 合成数据**（复现"管线"而非下载）：
- 把配方写清：纯净源 + 噪声源 + SNR 范围 + 混音参数 + 采样率 + 划分 seed；
- 各原料（纯净语音库、噪声库）按上面的方法分别收齐；
- manifest（论文代码里的绝对路径清单）→ 用论文提供的 `make_dataset_json.py --prefix` 之类脚本**重建**，别硬改原文件。

**等作者开源但暂无链接** → 状态 `⛔（等开源）`，§7 待办登记：关注作者 GitHub/项目页，或留 issue/邮件问一句。

## 5. 类 4 · 权重与训练配置

- **官方权重**：GitHub release / Hugging Face / 项目页 "Pretrained" → 下载到 `资料/权重配置/`，记来源 commit + 校验和（可选）。
- **训练 config / 超参 yaml**：随代码镜像已收的，不需重复收（备注"随代码"）；仅论文附录给出（无代码）时手动抄录到 `资料/权重配置/`。
- **无官方权重** → 状态 `⛔（需自训）`：把"自训到该表需多少算力"写入复现 README 作为预期；权重非必须时可只走评测脚本用论文声称值做参照（如实标注）。
- 权重**许可**常与代码不同（如仅研究用途），单独记。

---

## 6. 类 5 · 评测与指标脚本

- **官方 evaluate**：在官方代码内 → 复制到 `资料/评测脚本/` 并**保持原样**（复现时调它，别顺手改坏口径）。
- **指标包与版本**：pesq（宽/窄带差异大）、pystoi（extended?）、DNSMOS（需联网）→ pip 安装并在 `复现/README.md` §2 记版本；这是"指标对不上"的第二大坑。
- **无官方评测**：复现时按论文口径自写评测脚本，留档 `资料/评测脚本/`，写明口径（划分/SNR/采样率/指标参数/seed）。
- 评测脚本的输入输出要与论文表一致（哪几行是哪个配置）→ 对齐时逐格对照。

## 7. 类 6 · 环境与依赖锁定

- **原版依赖文件**：随代码镜像收 requirements.txt / environment.yml（原样保留 + 记 commit）。
- **实测锁定**：复现环境装好后 `pip freeze > 复现/环境冻结.txt`（或 conda env export）留痕；README §2 记 Python/CUDA/框架/关键包版本与 GPU。
- **硬约束**提前识别：如"需 Linux + CUDA、Windows 无 mamba_ssm 支持、py≤3.12、torch 2.2"→ 写在备注列，作为环境就绪判定（`import 库` + `torch.cuda.is_available()` 过）。
- 环境类条目多数在复现步骤 3 才真"收集"，分析阶段标 `☐` + 备注约束即可。

## 8. 状态语义与何时请用户介入

| 状态 | 含义 | 谁的活 |
|------|------|--------|
| `☐` 未收集 | 还没动 | 复现步骤执行 |
| `🔄` 收集中 | 已定位/部分到手，还差一步 | 复现步骤执行 |
| `✅` 已收 | 在正确位置、可复现用 | — |
| `⛔` 受阻 | 需用户介入 / 等开源 / 未公开 / 受限 | **停下来请你定** |

**何时该停请你介入**（别自己卡死或越权）：
1. 受限数据需你手动下载放入 → 给你官方入口 + 许可，等你放完再标 ✅；
2. 无官方代码/权重 → 问你：走手搓 or 邮件作者 or 放弃该项（⛔ 决策）；
3. 作者称将开源但无链接 → 问你：等 / 追踪登记 / 改用第三方；
4. 拿不准某项归属或检索方向 → 问一句，别猜。
> 复现收尾（步骤 8）回写：涉及项更新为 ✅/⛔，刷新 §0 总览，并把 ⛔ 汇总进复现 README 的卡点表。

## 9. 常见卡点速查

| 现象 | 处理 |
|------|------|
| 官方仓库不存在 / 404 | 换检索词（GitHub topics、PapersWithCode、引文）；作者主页搜"code/software"；仍无 → `⛔ 未公开` + 手搓 |
| 仓库太大不想整体镜像 | 只记 URL + commit（"仅链接"）；需要时才稀疏检出子目录 |
| 数据要登录/申请 | 只记入口+许可，请用户放入（`☐ 需用户放入`） |
| manifest 是绝对路径清单 | 落地数据后用论文重建脚本重造，别改原 manifest |
| 权重无官方版 | `⛔ 需自训`，算力预期写 README；能靠评测口径先对齐则说明标注 |
| Windows 上克隆/路径报错 | 中文路径加引号；文件夹禁半角 `:`；命令用 `C:/…` 全路径 |
| 检索超时盒（15–20 min） | 未确认项写"未查/待查"进 §7，不无限查 |
